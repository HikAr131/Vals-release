# Vals

Vals 的公开问题反馈与发布渠道；程序源代码保存在私有仓库。

## 下载

[下载最新版 vals.exe](https://github.com/HikAr131/Vals-release/releases/latest/download/vals.exe) · [版本说明](https://github.com/HikAr131/Vals-release/releases/latest)

当前版本 **0.0.10**，供内测群测试与反馈。Windows x64 单文件便携程序，需要 Microsoft Edge WebView2 Runtime；运行时会请求管理员权限，无需安装。

支持自动／手动主显示器调整、NVIDIA 自定义分辨率、NVIDIA／AMD GPU 缩放、可搜索的自动目标选择、灵敏度换算、通知、系统托盘、登录自启、简体／繁体中文及签名校验的自动更新。AMD GPU 缩放仅适用于支持的单个直连主显示器，实际硬件效果仍待内测；暂不支持创建 AMD 自定义分辨率。

本次更新：反馈问题时必须填写问题描述，保存的诊断包会附上 note.txt，包含描述、UTC 时间与版本。常见路径、账号、凭证与标识符会遮罩，但分享前仍请自行检查描述中的私人信息；「关于我们」仍可导出不含描述的诊断包。

无法使用 GitHub 时，可展开电子邮件三步指引：先填写描述并将诊断包另存到桌面，再使用常用邮箱向 hikarios@163.com 写信，最后自行附上 ZIP 并发送。支持拷贝邮箱地址，以及保存后在文件资源管理器中显示文件；不会自动上传或发送邮件。

「一键拉伸」期间持续显示黑边排查指引；诊断包补充当前显示模式，并为 DISPLAY_QUERY 错误记录固定查询阶段与数值状态，方便回报时判断失败位置。本次没有修改显示、缩放或还原机制，不代表游戏上下黑边的根因已修复；停用中切换、实际游戏拉伸效果与硬件行为仍需实机验证。

如需降回 0.0.6，请先使用新版完成还原并正常退出；0.0.6 无法读取新版在崩溃或断电后可能留下的恢复记录。

## 内测问题反馈

1. 点击侧栏最下方的「反馈问题」，先填写问题描述，再保存诊断包；默认保存在桌面，也可以自己选择位置。「关于我们 → 日志与反馈」仍保留不含问题描述的导出入口。
2. 使用 GitHub 时，点击「打开反馈页」或[提交问题](https://github.com/HikAr131/Vals-release/issues/new?template=bug_report.yml)，补充重现步骤与预期结果，并拖入诊断 ZIP。公开 Issue 和附件所有人都能看见。
3. 不方便使用 GitHub 时，展开「不方便用 GitHub？改用电子邮件发送」：保存诊断包 → 用常用邮箱向 hikarios@163.com 写信，主题为「Vals反馈」→ 将 ZIP 作为附件自行发送。地址可以拷贝；保存后可点「在文件夹中显示」找到文件。

诊断包仅保存在本机，由使用者主动提交，不自动上传或发送邮件。包含软件版本、系统与显示摘要、经过筛选的操作与恢复记录，以及反馈流程填写的 note.txt（问题描述、UTC 时间与版本）。自动摘要不收集游戏配置原文、账号、设备实例路径、更新私钥或完整用户目录；描述中的常见私人模式会遮罩，但自由文字仍可能包含未识别的私人信息，分享前请自行检查。截图与附件也请先检查，勿附账号、私人路径、游戏账号截图、证书或密钥。

已完成程序与自动验证；真实游戏、显示模式切换、黑屏恢复、登录自启及其他电脑仍待内测验收。显示模式与监视器操作可能短暂黑屏，请先保存工作；断电、驱动或系统故障可能中断自动恢复。
