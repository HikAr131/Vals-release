# Vals

Vals 的公开问题反馈与发布渠道；程序源代码保存在私有仓库。

## 下载

[下载最新版 vals.exe](https://github.com/HikAr131/Vals-release/releases/latest/download/vals.exe) · [版本说明](https://github.com/HikAr131/Vals-release/releases/latest)

当前版本 **0.0.7**，供内测群测试与反馈。Windows x64 单文件便携程序，需要 Microsoft Edge WebView2 Runtime；运行时会请求管理员权限，无需安装。

支持自动／手动主显示器调整、NVIDIA 自定义分辨率、NVIDIA／AMD GPU 缩放、可搜索的自动目标选择、灵敏度换算、通知、系统托盘、登录自启、简体／繁体中文及签名校验的自动更新。AMD GPU 缩放仅适用于支持的单个直连主显示器，实际硬件效果仍待内测；暂不支持创建 AMD 自定义分辨率。

本次更新：修复自动模式在游戏期间未持续停用监视器的问题，手动停用支持确认保留；改善原始分辨率还原、错误反馈与诊断，并提示 cfg 拉伸方式暂时失效。

请先开启自动模式，再启动游戏；本次更新后需要重新确认免责声明。游戏内拉伸效果、AMD 实机及异常退出恢复仍需内测验证。

如需降回 0.0.6，请先使用 0.0.7 完成还原并正常退出；旧版无法读取新版在崩溃或断电后可能留下的恢复记录。

## 内测问题反馈

1. 点击侧栏最下方的「反馈问题」，保存诊断包后打开反馈页；「关于我们 → 日志与反馈」也保留导出入口。
2. [提交问题](https://github.com/HikAr131/Vals-release/issues/new?template=bug_report.yml)，填写版本、操作步骤、预期结果与实际结果，并拖入诊断 ZIP。
3. 公开 Issue 和附件所有人都能看见。请勿附账号、私人路径、游戏账号截图、证书或密钥；只附由 Vals 导出的诊断包及自行检查过的截图。

诊断包仅保存在本机，由使用者主动提交，不自动上传。包含软件版本、系统与显示摘要、经过筛选的操作与恢复记录；不包含游戏配置原文、账号、设备实例路径、更新私钥或完整用户目录。

已完成程序与自动验证；真实游戏、显示模式切换、黑屏恢复、登录自启及其他电脑仍待内测验收。显示模式与监视器操作可能短暂黑屏，请先保存工作；断电、驱动或系统故障可能中断自动恢复。
